# Scolyer releases

Installers and update files for [Scolyer](https://scolyer.com). Download the newest version from
[scolyer.com](https://scolyer.com) or the [latest release](../../releases/latest).

The source code is not here. Releases are built and drafted by Scolyer's private repository and
published by hand; publishing one removes the older releases
(`.github/workflows/prune-releases.yml`).
